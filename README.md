# peripheral-view

YouTube、ニコニコ動画、bilibiliの映像の端を3D空間の壁へ投影し、映画館の多面上映のように視聴するブラウザ拡張機能です。Chromeと、Firefox 140以降に対応しています。
ビルドは不要で、WebGL2で描画します。

## 導入

### Chrome

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ
4. 開いていたYouTube、ニコニコ動画、bilibiliのタブを再読み込みする

`browser_specific_settings` はFirefox用の設定です。Chromeで不明なキーとして警告が出ても、動作には影響しません。

### Firefox

1. Firefoxのアドレスバーに `about:debugging#/runtime/this-firefox` と入力して開く
2. 「一時的なアドオンを読み込む」を押す
3. このフォルダの `manifest.json` を選ぶ
4. 開いていたYouTube、ニコニコ動画、bilibiliのタブを再読み込みする

この方法で読み込んだアドオンは、Firefoxを終了すると消えます。
常用するには、[addons.mozilla.org](https://addons.mozilla.org/developers/) で署名を受けて `.xpi` を入れます。ストアに公開しない「自分で配布」の署名でも使えます。

## 使い方

- プレーヤー右下の全画面ボタンの左にあるボタンで開始します
- モード中にもう一度そのボタンを押すと、設定パネルが開きます。全画面のまま選択でき、パネルの「終了」で終わります
- `Alt+X`（Macは `Option+X`）でも開始と終了を切り替えられます。`Esc` などで全画面を抜けても終了します
- 同じ設定はツールバーの拡張機能アイコンからも変更できます。アイコンが見当たらないときは、パズルのアイコンの中にあります

| 設定 | 内容 |
|---|---|
| スクリーン | 3面（左右）、4面（左右＋上）、5面（左右＋上下） |
| 席の位置 | 前方、中央、後方。後ろほど中央スクリーンが小さくなり、壁は常に画面端まで続きます |
| 平均の方法 | 均等か、端に近いピクセルほど重くする「端を重視」 |
| 中央スクリーンの大きさ | 前方席での大きさ |
| 端から平均する幅 | 映像の端から何%の幅を平均するか |
| ぼかす範囲 | 平均した色を、映像の高さの何%の範囲でぼかすか |
| 明るさ | 周囲のスクリーンの明るさ |

## 仕組み

- 中央は本物の `<video>` をCSSで縮小しているので、字幕、コメント、弾幕、操作バーは各サイトのものがそのまま使えます
- `<video>` の背面に置いたcanvasへ、壁、床、天井（4面と5面では上下のスクリーン）をWebGLで描いています
- 壁には映像の左右の端付近の色を行ごとに平均し、縦方向にぼかしてから横へ引き伸ばして投影します
- 4面と5面では上下の端の色を同じように列ごとに平均し、上下のスクリーンへ投影します
- サイトごとの違いは `src/sites.js` にまとめています

## Ambient light for YouTube との関係

同時に有効にして使えます。ただし、壁の映像は本拡張が独自に描いています。
Ambient lightには他の拡張へ映像を渡す仕組みがなく、全画面ではプレーヤーの背面にあるその光も隠れるためです。

## 制限

- DRM付きの動画は映像を読み取れないため、壁が黒くなります
- 16:9の全画面では、中央を縮めた分だけ映像が小さくなります
- YouTube、ニコニコ動画、bilibiliの画面構成が変わると、調整が必要になることがあります
- ニコニコ動画の4:3動画では、コメントが映像の幅より外の壁にも重なります
