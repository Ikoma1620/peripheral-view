# peripheral-view

YouTube、ニコニコ動画、bilibiliの映像の端を3D空間の壁へ投影し、映画館の多面上映のように視聴するブラウザ拡張機能です。Chrome、Edgeと、Firefox 140以降に対応しています。
ビルドは不要で、WebGL2で描画します。

## 導入

### Chrome、Edge

1. Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開く
2. 「デベロッパー モード」（Edgeでは「開発者モード」）をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ
4. 開いていたYouTube、ニコニコ動画、bilibiliのタブを再読み込みする

`browser_specific_settings` はFirefox用の設定です。Chromeで不明なキーとして警告が出ても、動作には影響しません。

### Firefox

1. Firefoxのアドレスバーに `about:debugging#/runtime/this-firefox` と入力して開く
2. 「一時的なアドオンを読み込む」を押す
3. このフォルダの `manifest.json` を選ぶ
4. 開いていたYouTube、ニコニコ動画、bilibiliのタブを再読み込みする

この方法で読み込んだアドオンは、Firefoxを終了すると消えます。
常用するには、[addons.mozilla.org](https://addons.mozilla.org/developers/) で署名を受けて `.xpi` を入れます。ストアに公開しない「自分で配布」の署名でも使えます。

## 使い方

- プレーヤー右下の全画面ボタンの左にあるボタンで開始します
- モード中にもう一度そのボタンを押すと、設定パネルが開きます。全画面のまま選択でき、パネルの「終了」で終わります
- `Alt+X`（Macは `Option+X`）でも開始と終了を切り替えられます。`Esc` などで全画面を抜けても終了します
- 同じ設定はツールバーの拡張機能アイコンからも変更できます。アイコンが見当たらないときは、パズルのアイコンの中にあります

映像の比率と正面スクリーンの比率はプルダウンで選び、選択肢は共通です。スタンダード（4:3）、大型フィルム（1.43:1）、テレビ・配信（16:9）、映画の標準ワイド（1.85:1）、デジタルシネマ（1.90:1）、配信ドラマのワイド（2:1）、映画の横長ワイド（2.39:1）から選べます。

| 設定 | 内容 |
|---|---|
| スクリーン | 3面（左右）、4面（左右＋上）、5面（左右＋上下） |
| 見た目 | 「標準」（初期設定）か「劇場（座席・床・天井）」。下の「見た目：劇場」を参照 |
| 描画方式 | 「端の色を延ばす」（初期設定）か「動きに追従」。下の「描画方式」を参照 |
| 映像の比率 | そのまま、または上の比率から選びます。元の比率と異なる場合は上下か左右を切り取るので、黒帯付きで作られた映像の黒帯を除けます |
| 正面スクリーンの比率 | そのまま（映像に合わせる）、または上の比率から選びます |
| 映像の合わせ方 | 「全体を表示」は映像を欠けさせず、余った部分にも映像の端の色を延ばして投影します。「切り取って埋める」はスクリーン全体を映像で埋め、はみ出た部分と壁の色の元になる端を切り取ります |
| 席の位置 | 前方、中央、後方。後ろほど正面スクリーンが小さくなり、壁は常に画面端まで続きます |
| 平均の方法 | 均等か、端に近いピクセルほど重くする「端を重視」 |
| 正面スクリーンの大きさ | 前方席での大きさ |
| 端から平均する幅 | 映像の端から何%の幅を平均するか |
| ぼかす範囲 | 平均した色を、映像の高さの何%の範囲でぼかすか |
| 明るさ | 周囲のスクリーンの明るさ |
| 動きの追従 | 「動きに追従」のときだけ表示。カメラの動きに合わせて映像を壁へ流す強さ。0%で端の色の光だけになります |
| 残像の長さ | 「動きに追従」のときだけ表示。壁へ流れた映像が薄れるまでの長さ |
| 連続部分を端まで描く | 「動きに追従」のときだけ表示。空や地平線のように端へ向かって連続している部分を、ぼかさず暗くしすぎずにスクリーンの端まで描く強さ。0%でPeriphery と同じ描き方になります |

## 仕組み

- 中央は本物の `<video>` をCSSで縮小しているので、字幕、コメント、弾幕、操作バーは各サイトのものがそのまま使えます
- `<video>` の背面に置いたcanvasへ、壁、床、天井（4面と5面では上下のスクリーン）をWebGLで描いています
- 壁には映像の左右の端付近の色を行ごとに平均し、縦方向にぼかしてから横へ引き伸ばして投影します
- 4面と5面では上下の端の色を同じように列ごとに平均し、上下のスクリーンへ投影します
- サイトごとの違いは `src/sites.js` にまとめています

## 見た目：劇場

部屋を映画館のように描きます。壁（と4面・5面の上下のスクリーン）への投影は「標準」と同じで、「描画方式」はどちらも使えます。

- **座席表**：設定の「見た目」のすぐ下に、元にしたシアターの座席表が出ます。席を押すと、その席の位置（左右のずれ、スクリーンまでの距離、段の高さ）から見た景色になります。「「席の位置」の設定に戻す」で、席の位置（前方はE列、中央はG列、後方はJ列の中央の席）に戻ります
- **座席**：自分より前の列が、座席表どおりの並び（中央15席と左右のブロック、幅の広い席の列、C列とD列の間の横通路、車椅子スペースの空き）と向きで見えます。左右のブロックのように図面で斜めに置かれた席は、背もたれも斜めに並びます。黒い背もたれの上端はスクリーンの光を受けます
- **床**：劇場のカーペット（グレーに、濃いグレーの菱形の格子と明るいグレーの点の柄）です。3列目から後ろは1列ごとに段になり、通路では段の先端に足元灯が並びます。5面では最前列より前の床が下のスクリーンになります
- **正面スクリーン**：座席表どおりの幅（14.85m）で、下端は左右のスクリーンのいちばん低い所と同じ高さ（床から1.55m）です。「正面スクリーンの比率」を変えると高さだけが変わり、天井もそれに合わせて上下します（横長ワイドでは低く、標準ワイドやテレビ・配信では高くなります）
- **左右のスクリーン**：正面スクリーンの端と左右の壁の間（片側0.95m）は、奥行きの向きから22.5度開いた斜めのスクリーン（奥行き約2.3m）でつなぎ、その先は壁に沿って奥へ延びます。吸音パネルの壁からわずかに浮かせて付け、壁に影を落とします。下端は座席の背もたれの50cm上（床から1.55m）までで、客席の段に沿って後ろほど下が削られます（自分より後ろの列の分も含みます）。映像は壁に沿って14mの長さに延ばし、席を替えても壁の同じ所に同じ映像が映ります
- **出入口の仕切り**：D列からJ列の左右にある出入口の通路を、客席と仕切る低い壁です。高さは隣の座席の背もたれより10cm上で、客席の段に沿って上がります。通路の後ろの端（出入口の側）も同じ高さの壁でふさぎ、図面で斜めの壁は斜めに描きます
- **プロジェクター**：左右のスクリーンの上（4面と5面では上端）に片側4台あり、部屋の奥行きを4等分した区画の中央に1台ずつ並びます。レンズは、向かいの壁へ映している映像の色で光ります
- **天井**：3面では、スクリーンの上端より約0.87m高くして、20cm角の細かい格子を描き、スクリーンの上下は黒い幕にします。4面と5面では、上のスクリーンがそのまま天井になります
- **視線**：選んだ席の目の位置から、正面スクリーンの中心を見ます。どの席でも映像の中心が画面の中央に来て、席が端や前になるほど正面スクリーンは斜めに（台形に）見えます。実際の `<video>` と字幕やコメントの層にも、同じ遠近の変形をCSSでかけます。最前列や端の席では画角が広がり、画面の端は真横より後ろを向くことがあります。その向きには、後ろへ続く壁と天井、自分の列の床を描きます
- 「正面スクリーンの大きさ」は、前方（E列）の正面から見たときの大きさです。画角はこれで決まり、遠い席ほど小さく、近い席ほど大きく見えます。近い席や端の席でスクリーンが画面からはみ出すときは、画面の92%に収まるまで画角を広げます
- 座席表は `theaters/theater-7.json` です。幅16.75m、12列246席のシアターのもので、座席表の作成ツールが書き出したファイルをそのまま入れています。座席表にない寸法は想定です（段差は1列40cm、天井はスクリーンの上端から約0.87m）
- 描画は `src/theater.js` にまとめています

### 別のシアターを読み込む（そのページだけ）

プレーヤーの設定パネルの座席表の下にある「座席表のファイルを読み込む（このページだけ）」で、同じ形式のJSONファイルを選ぶと、そのシアターで表示します。

- 読み込んだシアターと、そこで選んだ席は保存しません。ページを閉じるか再読み込みすると、元のシアターに戻ります。「元のシアターに戻す」でも戻せます
- ツールバーのポップアップには、このボタンはありません。ポップアップの座席表は、いつも元のシアターです
- ファイルを選ぶ窓を開くと全画面が解除されることがあります。そのときは、お知らせに従って peripheral-view のボタンをもう一度押すと全画面に戻ります
- ファイルから読むのは、スクリーンの位置と幅（`screen`）、座席（`seats`）、車椅子スペースの種類（`seatTypes`）、壁（`objects` の `wall`）、目の高さ（`settings.eyeHeight`）です。左右それぞれでいちばん長い縦の壁を部屋の壁とし、その内側にある縦の壁を出入口の通路の仕切りとみなします。幅70cm以上の席は、幅の広い席として背もたれを高くします
- 「席の位置」の前方・中央・後方は、列の数に合わせて決めます（12列なら E、G、J 列）
- 前に見える列は16列まで、1列の中のブロック（通路や向きで区切られた席の並び）は5つまでです

使う権限に追加はありません。座席表のファイルをページ内のスクリプトから読むために、`manifest.json` の `web_accessible_resources` に `theaters/theater-7.json` を入れています。

## 描画方式

- **端の色を延ばす**（初期設定）：これまでの描き方です
- **動きに追従**：[Periphery 環繞延伸](https://github.com/Tro999999/periphery) の描き方を、壁と上下のスクリーンに合わせて組み直したものです
  - 縮小した映像から画面全体の動きを推定し、カメラが振られたときは映像の外へ出た部分を壁へ流します
  - 映像に焼き込まれた黒帯を自動で見つけ、本当の映像の端から色を取ります
  - 場面転換やシークでは、壁に残った前の映像を消します
  - 端の色は、映像から遠いほど端に沿って広がる光にし、遠いほど強くぼかします
  - ただし、端から内側へ向かって色がほとんど変わらない行や列（空、地平線、壁、なだらかな階調）と、カメラの動きで流れてきた映像は「連続している」とみなし、広げず、ぼかさず、奥でも暗くしすぎずにスクリーンの端まで描きます。模様の細かい部分は従来どおりやわらかく消えていきます
  - 「端から平均する幅」「平均の方法」「明るさ」はこの方式でも使います。「ぼかす範囲」は光の広がり方に使います

「動きに追従」は毎フレーム縮小画像をCPUへ読み戻して解析するので、「端の色を延ばす」より負荷が高くなります。

## Ambient light for YouTube との関係

同時に有効にして使えます。ただし、壁の映像は本拡張が独自に描いています。
Ambient lightには他の拡張へ映像を渡す仕組みがなく、全画面ではプレーヤーの背面にあるその光も隠れるためです。

## 制限

- DRM付きの動画は映像を読み取れないため、壁が黒くなります
- 16:9の全画面では、中央を縮めた分だけ映像が小さくなります
- YouTube、ニコニコ動画、bilibiliの画面構成が変わると、調整が必要になることがあります
- ニコニコ動画の4:3動画では、コメントが映像の幅より外の壁にも重なります
